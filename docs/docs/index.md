# Tech Event Support for Plone

Welcome to the documentation for Tech Event Support for Plone.

Tech Event Support for Plone helps you build a tech conference, symposium or seminar site.
It has two parts that work together.
The backend add-on, `collective.techevent`, adds the event, the schedule, the presenters, the venues and the sponsors to a {term}`Plone` site.
The Volto add-on, `@plone-collective/volto-techevent`, shows them to your visitors.

The documentation follows the [Diátaxis](https://diataxis.fr/) framework.
Start with the tutorial if you are new to the add-on, or go straight to the how-to guides if you already know it.
